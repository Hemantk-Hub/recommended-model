🎬 Built a Movie Recommendation System with Python and Streamlit!

I just finished a project that suggests similar movies based on the one you select.

How it works:
🔹 Movie data is processed into feature vectors
🔹 Cosine similarity finds the closest matches
🔹 Streamlit gives it a simple, interactive web interface

Tech stack: Python | Pandas | Scikit-learn | Joblib | Streamlit

What I learned:
✅ Building a content-based recommender
✅ Optimizing large similarity files for deployment
✅ Debugging virtual environments and dependencies
✅ Deploying an ML app on the web

Watch the demo video below 👇 Pick any movie and get 5 recommendations instantly.
